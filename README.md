# MiniMappingway

[jaycewhite/MiniMappingway](https://github.com/jaycewhite/MiniMappingway) 的台服移植版。
在小地圖上顯示好友、公會成員與周圍玩家的插件。

## 主要功能

- **小地圖標點**：依來源（好友、公會成員、附近所有玩家）分類標示，可各自設定啟用、顏色、標點大小、邊框。
- **PvP 玩家雷達**（預設關閉）：在紛爭前線等 PvP 區域以螢幕標點顯示周圍可接收到的玩家，可設定僅顯示判定點（不顯示名稱）、不顯示友方、標點半徑，並依三方陣營（黑渦團／雙蛇黨／不滅隊）上色；可選擇在非 PvP 區域也顯示。
- **「鎖定我的人」連線層**：從每個把自己選定為目標的玩家畫線到自己，並在自己身上顯示鎖定人數；可選擇一併顯示「注視方向指向我但硬目標未確認」的連線（因台服部分資料欄位可能取不到，這是唯一備援來源）。
- **設定視窗**：調整以上顯示項目與顏色。
- **IPC**：別的插件可以新增自己的標點來源與標記對象（玩家或寶箱這類非玩家物件皆可）。

## 指令

- `/mmway`：開關設定視窗

## 台服版的修改

- 新增 PvP 玩家雷達與「鎖定我的人」連線層
- IPC 標記可以標寶箱這類非玩家物件；別的插件透過 IPC 加標記時改在遊戲主執行緒處理，不再可能把遊戲弄崩
- 降低記憶體用量
- 介面繁體中文化
